Core Functions: calc_cos.R

The R/calc_cos.R script provides functions to calculate cosine similarity, a common metric to measure the similarity between two non-zero vectors. In the context of mutational signatures, it is a fundamental method used to compare an observed mutational spectrum from a sample against a catalog of known reference signatures. A higher cosine similarity value indicates a greater resemblance between the sample's spectrum and the reference signature.

This script contains two main functions:

  1. cosine(x, y): Calculates the raw cosine similarity between two numeric vectors.
  2. calc_cos(spectrum, signatures): Applies the cosine() function to compare a given mutational spectrum against each signature in a reference set (matrix), then identifies the best match.

1. cosine(x, y)​

Purpose​

This is a direct mathematical helper function that computes the cosine similarity between two numeric vectors, x and y. The formula implemented is:

Similarity = (X · Y) / (||X|| * ||Y||)

Where:

  • X · Y is the dot product of vectors x and y. In R, this is calculated as x %*% y.
  • ||X|| is the Euclidean norm (or magnitude) of vector x, calculated as sqrt(x %*% x).
  • ||Y|| is the Euclidean norm of vector y, calculated as sqrt(y %*% y).

The resulting similarity value quantifies the cosine of the angle between the two vectors.

Inputs​

ParameterTypeDescription
xNumeric VectorThe first vector (e.g., a sample's mutational spectrum or a reference signature).
yNumeric VectorThe second vector (e.g., a reference signature or another sample's spectrum).

Outputs​

  • A single numeric value representing the cosine similarity. This value ranges from -1 (vectors point in exactly opposite directions) to 1 (vectors point in the exact same direction). A value of 0 indicates the vectors are orthogonal. For mutational spectra, which typically contain non-negative mutation counts or proportions, the cosine similarity values range from 0 to 1.

2. calc_cos(spectrum, signatures)​

Purpose​

This function systematically compares a single input mutational spectrum (from a sample) against a collection of reference mutational signatures. It achieves this by applying the cosine() function to the input spectrum and each reference signature iteratively. It then summarizes these comparisons by identifying the reference signature that is most similar to the input spectrum.

Inputs​

ParameterTypeDescription
spectrumNumeric VectorA single mutational spectrum. This vector's length must match the number of rows in the signatures matrix (e.g., 96 channels for a standard trinucleotide context spectrum).
signaturesNumeric MatrixA matrix where each column represents a distinct reference mutational signature. The rows correspond to the mutation channels (e.g., 96 rows, matching the spectrum). The column names of this matrix are used as identifiers for the signatures in the output.

Outputs​

The function returns a list containing the following four elements:

  • simils: A named numeric vector.
    • Names: These are the column names extracted from the input signatures matrix (i.e., the names of the reference signatures).
    • Values: The cosine similarity score calculated between the input spectrum and each corresponding reference signature in the signatures matrix.
  • ind_max: An integer. This is the 1-based column index in the original signatures matrix that corresponds to the reference signature yielding the highest cosine similarity with the input spectrum. If multiple signatures result in the exact same maximum similarity value, the index of the first one encountered during the apply operation is returned.
  • sig_max: A string. The name (column name from signatures) of the reference signature that exhibits the highest cosine similarity to the input spectrum. This corresponds to colnames(signatures)[[ind_max]].
  • max_val: A numeric value. The actual maximum cosine similarity value found among all comparisons. This is equivalent to simils[[ind_max]].

Key Algorithmic Logic​

  1. Iterative Comparison: The function uses apply(signatures, 2, function(x){ cosine(spectrum, x) }).
    • apply(signatures, 2, ...) iterates over the columns (margin 2) of the signatures matrix.
    • For each column (let's call it x, representing a single reference signature), it executes the anonymous function function(x){ cosine(spectrum, x) }.
    • This anonymous function calls cosine(spectrum, x), computing the similarity between the fixed input spectrum and the current reference signature x.
    • The result of apply is a numeric vector where each element is the cosine similarity for the corresponding signature, and the names of this vector are taken from the column names of signatures. This vector is stored in simils.
  2. Identification of Maximum Similarity:
    • ind_max <- which(max(simils) == simils): This finds the index (or indices if there are ties) of the element(s) in simils that are equal to the maximum value in simils.
    • if(length(ind_max) > 0) ind_max = ind_max[[1]]: If there are ties for the maximum similarity, this line ensures that only the first index among the ties is selected. This provides a deterministic way to break ties.
  3. Extraction of Best Match Details:
    • sig_max <- colnames(signatures)[[ind_max]]: Retrieves the name of the best-matching signature using the determined index.
    • max_val <- simils[[ind_max]]: Retrieves the maximum similarity value itself.
  4. Return Value: The function bundles simils, ind_max, sig_max, and max_val into a list and returns it.

This script is a fundamental component of many signature analysis workflows, providing a straightforward and interpretable measure of similarity. It's often one of the first analyses performed when trying to attribute a sample's mutational profile to known etiological processes represented by reference signatures.
