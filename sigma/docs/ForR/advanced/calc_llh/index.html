Core Function: calc_llh()

The R/calc_llh.R script contains the calc_llh() function. This function calculates a score related to the likelihood (specifically, a sum of log-likelihoods) of an observed mutational spectrum given a set of reference mutational signature probability distributions. It's a key method for assessing which reference signature or signature cluster best explains a sample's mutational pattern.

Purpose​

The primary purpose of calc_llh() is to quantify how well each reference signature (often representing an average profile of a signature cluster) explains the input mutational spectrum. It computes a log-likelihood-based score for the spectrum under each provided signature model. The function includes an important normalization step to make these scores more comparable and to handle potential numerical instabilities. It also identifies the signature that provides the best fit based on these scores.

Inputs​

The calc_llh() function takes the following parameters:

ParameterTypeDefaultTechnical Description & Implications
spectrumNumeric VectorThe observed mutational spectrum for a sample (e.g., a 96-channel vector of mutation counts). This is treated as pow (powers or counts) in the log-likelihood calculation: sum(spectrum[i] * log(signature_j[i])).
signaturesNumeric MatrixA matrix where each column represents a reference mutational signature. These must be probability distributions (i.e., each column should sum to 1). Rows correspond to mutation channels.
countsNumeric VectorNULLOptional. A vector containing weights, typically the number of cases or prevalence of each signature/cluster represented in the signatures catalog. If provided and normalize = TRUE, these are used to weight the scaled probabilities before final normalization. Length must match dim(signatures)[[2]].
normalizeBooleanTRUEIf TRUE, the calculated raw log-likelihood scores undergo a complex normalization: filtering of low scores, exponentiation relative to the max score, optional weighting by counts, and scaling to sum to 1. If FALSE, the raw sum of log-likelihoods is returned.

Outputs​

The function returns a list containing:

  • probs: A named numeric vector.

    • Names: Column names from the signatures matrix.
    • Values: Normalized probabilities if normalize = TRUE, else raw log-likelihood scores.

  • ind_max: An integer. The column index in signatures for the signature with the highest probs value.

  • sig_max: A string. The name of the reference signature with the highest score.

  • max_val: A numeric value. The maximum score (probs[[ind_max]]) found.

Algorithmic Detail​

calc_llh <- function(spectrum, signatures, counts = NULL, normalize = TRUE) {
  eps <- 0.00001
  pow <- spectrum
  probs <- apply(signatures, 2, function(x) {
    prob <- 0
    for (i in 1:length(x)) {
      if (x[[i]] == 0) x[[i]] <- eps
      if (pow[[i]] > 0) prob <- prob + pow[[i]] * log(x[[i]])
    }
    return(prob)
  })

  if (normalize) {
    mean_probs <- mean(probs)
    q1_probs <- mean(probs[probs < mean_probs])
    inds_keep <- which(probs >= q1_probs)
    inds_rm <- which(probs < q1_probs)
    probs[inds_rm] <- 0
    max_probs <- max(probs[inds_keep])
    probs[inds_keep] <- exp(probs[inds_keep] - max_probs)

    if (!is.null(counts) && length(counts) == length(probs)) {
      probs <- as.numeric(unlist(probs)) * as.numeric(unlist(counts))
    }

    probs[inds_keep] <- probs[inds_keep] / sum(probs[inds_keep])
  }

  ind_max <- which(max(probs) == probs)
  if (length(ind_max) > 0) ind_max <- ind_max[[1]]
  sig_max <- colnames(signatures)[[ind_max]]
  max_val <- probs[[ind_max]]
  names(probs) <- colnames(signatures)

  return(list(probs = probs, ind_max = ind_max, sig_max = sig_max, max_val = max_val))
}

This function is a cornerstone for methods that assign samples to signature clusters or determine the most likely active signature based on probabilistic models.
