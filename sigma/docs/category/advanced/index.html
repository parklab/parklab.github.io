Advanced

Technical documentation of the codebase and manual inforamtion for advanced users.

📄️ System Architecture

This document describes the overall architecture of the SigMA project, including its directory structure, key components, and how they interact.

📄️ assignment()

The R/assignment.R script contains the assignment() function. This function is responsible for assigning a binary status (e.g., positive/negative, pass/fail) for a specific mutational signature based on whether a calculated score exceeds predefined or custom thresholds. It translates quantitative scores into qualitative, actionable calls.

📄️ calc_cos() & cosine()

The R/calc_cos.R script provides functions to calculate cosine similarity, a common metric to measure the similarity between two non-zero vectors. In the context of mutational signatures, it is a fundamental method used to compare an observed mutational spectrum from a sample against a catalog of known reference signatures. A higher cosine similarity value indicates a greater resemblance between the sample's spectrum and the reference signature.

📄️ calc_llh()

The R/calcllh.R script contains the calcllh() function. This function calculates a score related to the likelihood (specifically, a sum of log-likelihoods) of an observed mutational spectrum given a set of reference mutational signature probability distributions. It's a key method for assessing which reference signature or signature cluster best explains a sample's mutational pattern.

📄️ Data Structures

This document outlines the key data structures used as inputs to and produced as outputs by SigMA. It also touches upon important internal R object structures that SigMA relies upon, primarily loaded from sysdata.rda.

📄️ decompose()

The R/decompose.R script provides the decompose() function, which is a sophisticated routine for determining the contribution of known mutational signatures to an observed mutational spectrum (spect). It employs a Non-Negative Least Squares (NNLS) algorithm within an iterative framework to find the combination of signatures and their exposures (activities) that best reconstructs the input spectrum, minimizing a Frobenius norm-based error.

📄️ Options and Parameters

This section provides a comprehensive guide to the various options and parameters available in SigMA, primarily focusing on the main run() function. Understanding these is crucial for customizing SigMA's behavior for specific analyses.

📄️ run()

The R/run.R script defines the primary orchestrating function run()^. This function serves as the main entry point for executing the SigMA analysis pipeline. It integrates various computational steps, from data input and preprocessing to signature analysis, multivariate prediction, and results output. Its behavior is heavily controlled by a rich set of parameters.
